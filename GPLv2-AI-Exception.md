These supplemental terms supplement the GNU General Public License Version 2 ("GPLv2") applicable to the Licensed Work.

The purpose of these terms is to preserve the copyleft status of the Licensed Work against attempts to reproduce, replace, or substantially replicate the Licensed Work through artificial intelligence, machine learning, automated code-generation systems, or similar technologies, while expressly permitting software applications to be developed and used with the Licensed Work without those applications becoming subject to GPLv2 solely because the Licensed Work was used to create them.

1. Definitions
1.1 Licensed Work

"Licensed Work" means the software, source code, documentation, and other materials distributed under GPLv2 together with these supplemental terms.

1.2 Automated System

"Automated System" means any software, service, artificial intelligence system, machine learning system, neural network, code-generation system, source-transformation system, or similar technology capable of analyzing, transforming, generating, or otherwise producing software or other technical works.

1.3 Application

"Application" means software created by a person using the Licensed Work as a development tool, framework, library, runtime, build system, platform, or other development resource, where the resulting software is intended to provide functionality or services distinct from the Licensed Work itself.

1.4 AI Clone

"AI Clone" means a software work that is generated, substantially generated, or substantially developed through use of an Automated System where the Licensed Work, its source code, or a substantial portion of its source code has been supplied to, made available to, retrieved by, or otherwise used by the Automated System, and where the resulting work is intended to reproduce, replace, emulate, or substantially replicate the Licensed Work as a software product, development tool, framework, library, platform, or substantially equivalent implementation.

An AI Clone includes a work whose principal purpose or substantial effect is to provide a substantially equivalent substitute for the Licensed Work.

1.5 Modified Work

"Modified Work" has the meaning given to that term by GPLv2. For purposes of these supplemental terms, an AI Clone is expressly treated as a Modified Work.

2. Applications Built Using the Licensed Work

Use of the Licensed Work to create an Application does not, by itself, cause that Application to be a Modified Work or an AI-Derived Work.

In particular, an Application is not subject to GPLv2 solely because:

a. the Application was created using the Licensed Work as a development tool, framework, library, runtime, build system, or platform;

b. the Application uses interfaces, APIs, configuration mechanisms, or other documented functionality provided by the Licensed Work;

c. the Application was generated, assisted, tested, debugged, documented, or otherwise developed with the assistance of an Automated System that was used in connection with the Licensed Work; or

d. the Licensed Work was used during the ordinary development, testing, deployment, or operation of the Application.

This section does not grant permission to incorporate copyrightable portions of the Licensed Work into an Application where such incorporation would otherwise cause the Application to be a Modified Work under GPLv2.

3. AI-Assisted Development of Applications

The use of an Automated System to assist in developing an Application does not, solely for that reason, cause the Application to be a Modified Work.

For example, a person may use an Automated System to:

write application code that uses the Licensed Work;

debug an Application that uses the Licensed Work;

generate documentation for an Application; or

Nothing in these supplemental terms is intended to impose GPLv2 obligations on an Application merely because an Automated System was used during its development.

4. AI-Based Reproduction of the Licensed Work

Notwithstanding Sections 2 and 3, a person may not use an Automated System to circumvent, avoid, or materially reduce the copyleft obligations of GPLv2 by using the Licensed Work as a source for creating a substantially equivalent replacement for the Licensed Work.

Where the Licensed Work or a substantial portion of its source code is supplied to, retrieved by, or otherwise made available to an Automated System for the purpose of creating a substantially equivalent replacement, the resulting software is an AI Clone and is treated as a Modified Work.

An AI Clone includes, without limitation, software generated through instructions such as:

reproducing the Licensed Work;

rewriting the Licensed Work;

porting the Licensed Work to another programming language;

recreating the Licensed Work from its source code;

generating a functionally equivalent implementation from the Licensed Work's source code;

creating a replacement or alternative implementation of the Licensed Work based substantially upon its source code; or

otherwise using an Automated System to reproduce or substantially replicate the Licensed Work while attempting to avoid the GPLv2 obligations applicable to a Modified Work.

5. Source Code and Other Representations

For purposes of determining whether software is an AI Clone, the Licensed Work includes its source code and substantial representations of that source code.

Such representations may include, where they materially convey or encode the source code or its expressive implementation:

a. substantial excerpts;

b. source-code translations;

c. transformations of source code;

d. machine-readable representations;

e. embeddings or other representations generated from source code; and

f. summaries or other derived representations that are used as a substantial source for reproducing the implementation of the Licensed Work.

The mere use of general ideas, concepts, algorithms, programming techniques, publicly documented interfaces, or functionality embodied by the Licensed Work does not, by itself, make software an AI Clone.

6. Independent Development

Nothing in these supplemental terms restricts the independent development of software that does not use the Licensed Work or a substantial portion of its source code as a source for reproduction.

Software is not an AI Clone merely because it:

a. provides similar functionality;

b. competes with the Licensed Work;

e. was developed independently without using the Licensed Work as a source for reproduction; or

f. was created using an Automated System that did not receive the Licensed Work, a substantial portion of its source code, or a substantial representation of its source code as a source for generating the implementation.
