<tools>
The repository is checked out at the pull request's head, and the pull request's whole diff is written beside it as one patch per changed file. The file <diff index> names lists each changed file, one JSON line each: its path, status, line count and the patch files that hold it, a large patch split into numbered parts. Read the index, then read every line of every patch file with read_file, a page at a time. A deleted file has no patch file; skip it. Call grep and list, and read_file on other paths, for any other code you need. Repository paths are relative to the repository root and line numbers are head-side; the index and patch files are read at the /diff paths that name them, and grep does not search them. Your reads share a token budget; once it is spent, tool calls return an error and you answer with what you have.
</tools>
